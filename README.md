# Alter-Ego AI
#### The app is in Spanish
### Made UI to interact with an AI using Ollama (local AI) where you can see the AI reacting depending on what he says using Chihiro renders and behaviour, looking foward to add other things and upgrade the project.

### The idea is to make something similar to Alter Ego of Danganronpa Trigger Havoc, im still learning so don't expect a lot XD

## To make it work on your machine
### The thing is kinda complicated and its not working super well, and the buttons are in spanish but its nothing really strange, if you used any time Gemini, ChatGPT or any chat AI in general, is basically the same.
### First things first, this requires to have Ollama installed, basically its what makes the AI works, at the end of the day think that what I made is just an UI that reacts to what he says.

## Install Ollama and the AI
### Enter to the web and download it, pretty simple --> https://ollama.com
### After you download it, open a terminal (type cmd and open a console) and type "ollama pull gemma2:9b"
### this will install the model which is pretty heavy ngl, around 5.4GB so be sure to have space.

## Install AlterEgo
### Go to the link in the drive, download it and run the setup, a security pop will show, if this scares and you don't want to install then its fine but its safe so you shouldn't worry, just click on more details and install it anyways.
#### Think that the AI is locally on your pc using Ollama, I won't know that your favourite food is fried chicken so don't worry.

### Once you've done all this it should be working, just open the program and you will have the UI with Chihiro at the side, the fist message will take some time because the AI has to startup, the memory consume is not super big but if you have a really slow pc you may have some problems using other applications.
